# ATM Management System

A beginner-friendly, menu-driven ATM simulation built with Python and Object-Oriented Programming (OOP).

## Features

- Create a four-digit PIN
- Change an existing PIN after verification
- Check balance with PIN verification
- Withdraw money with amount and balance validation
- Handle invalid menu choices and numeric inputs
- Exit the ATM menu

## Concepts Used

- Classes and objects
- Constructor (`__init__`)
- Instance variables and methods
- `while` loops and conditional statements
- User input and basic validation

## Requirements

- Python 3

No external packages are required.

## Run the Project

From the project directory, run:

```bash
python atm.py
```

On some systems, use `python3 atm.py` instead.

## Limitations

This is an educational console project. PIN and balance are stored only in memory and reset when the program exits. It is not suitable for real banking or financial transactions.
